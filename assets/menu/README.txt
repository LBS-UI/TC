TAMBAYAN CAWAG — MENU PHOTOS
=============================

Drop real food photos into this folder using the exact filenames
below. The website will pick them up automatically — no code changes
needed. Recommended format: PNG or JPG, roughly 800x600px or similar
4:3 ratio, kept under ~300KB each for fast loading on mobile data.

If a file isn't here yet, the website automatically shows
placeholder.png instead (already included) so nothing looks broken.
